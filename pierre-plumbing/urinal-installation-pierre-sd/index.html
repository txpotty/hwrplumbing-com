    American Standard and Kohler Urinal Installation in Pierre

    American Standard and Kohler make the china we install most.     Urinal Brands We Install in Pierre, SD

    Brand choice is mostly about parts support. We recommend brands whose valves and cartridges are easy to get locally, so repairs never wait. We install all of them. Spec sheets come first.

    Residential Urinal Plumbing in Pierre, SD

    Home urinals use the same rules as commercial ones. The drain is usually 2 inch, the trap is built into the china, the fixture needs a vent within code distance, and the flush valve needs either a 3/4 inch supply or a lower-flow residential valve on 1/2 inch. Permit rules apply too. We check that first.

    ADA Urinal Installation in Pierre

    Accessible urinals start at the carrier. We set the carrier so the finished rim lands at 17 inches or lower, keep the clear floor space free of partitions and door swings, and mount the flush handle or sensor where a seated user can reach it. We measure the rim twice. Inspectors measure too.

    Waterless Urinal Installation in Pierre

    Waterless urinals save the most water and need the most discipline. A cartridge or sealing liquid blocks sewer gas while letting urine through, and it must be replaced on schedule. Your custodial team needs training. We show them how.

    Flush Valve Urinal Installation in Pierre, SD

    Flush valve urinals are the commercial standard. A flushometer from Sloan or Zurn delivers a measured volume from a 3/4 inch supply with no tank, and it recovers instantly for the next user, which matters in a stadium or school restroom. The volume matches the fixture rating. Wrong settings stain bowls.

    Urinal Installation Cost Factors in Pierre, SD

    Carrier work is the biggest cost swing. Reusing a carrier and lines is cheap, while new carriers and pipe runs through finished walls cost more. Touchless valves cost more than manual. We itemize each piece.

We lay out each urinal at 30 inches center to center and 15 inches from the side wall, set the carriers, and run waste, vent and supply so the finish crew can hang fixtures as soon as tile is done.
