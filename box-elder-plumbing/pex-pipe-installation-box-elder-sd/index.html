    Uponor PEX System Installation in Box Elder

    Uponor's ProPEX system is PEX-A joined with an expansion tool and a cold-expansion ring. The tech expands the pipe and ring together, pushes the fitting in, and the plastic shrinks back around the barb over the next few seconds, tighter than when it started. There is no crimp gauge to check. Because the fittings are wide inside, each joint costs very little flow.

    PEX-A Expansion Fitting Systems in Box Elder, SD

    With PEX-A, the tech slips a ring over the pipe end and stretches both with a battery tool. The fitting is pushed in while the pipe is open, and the plastic's memory shrinks it back around the barb, sealing tighter during the first minute. In the cold, it takes longer to shrink back. We let joints set before testing.

    PEX-B Crimp and Clamp Systems in Box Elder

    PEX-B is stiffer, costs less per foot, and joins with copper crimp rings or stainless cinch clamps over brass or poly-alloy fittings. A crimp joint is only as good as the tool, so we check every ring with a go/no-go gauge, and a ring that does not pass gets cut out and redone. It is a five-second check. Skipping it causes most crimp leaks.
